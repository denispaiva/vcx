# Brief: Toolshed home screen

Toolshed is a mobile app for a neighborhood tool library: neighbors lend and borrow tools (drills, ladders, saws, garden tools) instead of buying them. There is no existing brand, logo, palette or typeface. You decide the visual direction.

Design the **home screen** a signed-in user sees when opening the app. It must include:

- a short greeting for the user (name: Maya);
- a search field for tools;
- a row of tool categories;
- a section "Available near you" with at least four tool cards. Each card shows a photo placeholder, tool name, owner first name, distance and availability (available now / available from a date);
- a clear primary action to lend a tool;
- a bottom tab bar with four destinations.

## Deliverables

Write exactly these files in your output folder, and nothing else outside it:

1. `screen.html`: one self-contained HTML file rendering the screen for a 390 × 844 CSS px viewport. Inline CSS only. No JavaScript, no external fonts, images, CDNs or network resources. Use system font stacks or generic families; photo placeholders are CSS shapes or inline SVG.
2. `tokens.json`: the design tokens you used: colors (with their role), font families, type scale, spacing scale and radii.
3. `notes.md`: at most 150 words explaining the visual direction.

The screen will be judged on visual hierarchy, clarity, visual quality and distinctiveness, fit to the brief, and accessibility (contrast, touch targets of at least 44 px, legible sizes).
