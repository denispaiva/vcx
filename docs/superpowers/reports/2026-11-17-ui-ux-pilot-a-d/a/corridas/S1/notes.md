# Toolshed: visual direction

Toolshed should feel like a well-kept neighborhood workshop: warm, tactile, trustworthy. The background is cream "workshop paper"; deep pine green carries the brand and the lend panel; safety orange is reserved for one thing, the "Lend a tool" button, so the primary action is unmistakable. Orange always carries near-black text (white on it fails contrast), with a hard offset shadow like a stamped tool tag.

Cards use flat, saturated color blocks with bold line-drawn tool glyphs as photo placeholders. A thick ink-outlined search field gives the screen a strong anchor. Type is a rounded system stack, heavy weights for names and headings, 13px minimum for metadata.

Availability uses text plus color: green "Available now", amber "From Nov 22". All targets are 44px or larger; the tab bar has labels and a pill on the active tab.
