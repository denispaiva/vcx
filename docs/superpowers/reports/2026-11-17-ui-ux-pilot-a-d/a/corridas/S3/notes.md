# Direction: the workshop pegboard

Toolshed should feel like a well-kept neighborhood shed, not a fintech app. The background is warm paper with a faint pegboard dot grid. Cards, search and the tab bar get a bold ink outline and a hard offset shadow, like tools hung on a board.

Type pairs a slab-serif display face (Rockwell, falling back to Roboto Slab, then Georgia) for headings and the CTA with the system sans for everything else. Slab serifs feel like workshop signage and need no webfont.

Color is forest green for trust and selection, with one safety-orange accent reserved for "Lend a tool", the single primary action. Photo placeholders use four muted tool-box tints with simple tool silhouettes.

Availability uses a dot versus a square plus a label, so it never depends on color alone. All text is at least 12px and passes 4.5:1. Targets are 44px or larger.
