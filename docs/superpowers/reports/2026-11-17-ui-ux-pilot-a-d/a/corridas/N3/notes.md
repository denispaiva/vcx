# Visual direction

Toolshed should feel like a well-kept neighborhood workshop, not a tech marketplace. The background is warm paper cream. Deep forest green carries the brand, and a single safety-orange action, "Lend a tool", is the only warm accent, so the primary action is obvious.

Headings use a system serif (a workshop-sign feel) over a plain sans for UI text. Photo placeholders sit on pegboard-dot tints with simple tool glyphs. Availability uses tinted badges with text, not color alone.

Mobile first: every touch target is at least 44 px, body text is 13 px or larger, and all text pairs meet WCAG AA contrast (verified by calculation). The selected tab uses a pill and a heavier label, not color alone.
