# Visual direction: workshop warmth

Toolshed should feel like a friendly neighborhood garage, not a store. A warm paper background replaces cold white. Deep pine green carries the brand, headings and the lend banner. A single safety-orange is reserved for the one primary action, "Lend a tool", so it is unmistakable.

Hierarchy runs greeting, search, categories, lend banner, then the card grid. Cards use bold names, muted owner and distance, and a badge for availability; badges pair text with color, so state never relies on color alone. Photo placeholders are flat colored tiles with simple tool silhouettes.

Type is a rounded system stack. Text pairs meet 4.5:1, targets are 44 px or larger, body text is 14-16 px, and focus rings are visible.
