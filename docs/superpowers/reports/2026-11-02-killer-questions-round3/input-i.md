Idea ficticia: quiero ordenar un catálogo de piezas para los talleres de una escuela técnica. Hoy cada profesor usa sus nombres en una libreta; no medí errores ni tiempo perdido. Imagino una lista compartida con fotos, pero todavía no decidí si quiero ahorrar tiempo, enseñar clasificación o solo tener algo ordenado. Tampoco definí quién lo usaría, qué piezas entran, cuánto tiempo puedo dedicar ni qué presupuesto aceptaría. La decisión solicitada en esta revisión es identificar qué debo definir yo y qué requeriría observar en la escuela antes de elegir si explorar la lista. No hay autorización para construir ni para recopilar datos de alumnos.
