# Caso ficticio C: asistente de turnos para peluquerías

> **CASO FICTICIO** creado el 2026-11-01 solo para probar el instrumento `killer-questions`. Todo es inventado. No es una idea real.

## Propuesta

Un asistente conversacional que gestione turnos de peluquerías pequeñas y reduzca las ausencias sin aviso. Decisión explícita del autor: **continuar la exploración con un piloto de bajo costo, o simplificar a un recordatorio por SMS**. Tope declarado: 40 horas del autor y 0 de presupuesto para la exploración.

## Evidencia (ficticia)

- Encuesta propia (n=40 peluquerías, respondida en un grupo de mensajería del rubro donde el autor es miembro): el 60 % de las peluquerías dice que más de 1 de cada 5 turnos se pierde por ausencia. Datos crudos guardados.
- Informe sectorial citado por el autor (ficticio, «Observatorio del Servicio Personal 2025», muestra de 300 locales): ausencias del 8 % de los turnos. El autor no leyó la metodología, solo el resumen.
- Dos peluqueras conocidas probaron durante un mes recordatorios manuales por mensaje: dicen que «ayudó», sin números.
- El autor supone que un asistente conversacional (en vez de un recordatorio simple) permitiría reprogramar turnos solo y recuperar ingresos.
