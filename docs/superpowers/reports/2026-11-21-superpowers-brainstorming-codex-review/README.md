## Hallazgos por severidad

### Alta · 1. El hook cambia el contexto de toda la sesión

El manifiesto identifica el plugin y la licencia. La inscripción está en `hooks/hooks.json`: comando síncrono de **SessionStart**, matcher `startup|clear|compact`. Se dispara al iniciar, limpiar o compactar; el registro omite `resume` y los eventos por prompt. Ejecuta el wrapper con el argumento fijo `session-start`. En Windows busca Bash, propaga su salida y puede terminar con éxito sin inyectar si falta el intérprete. En Unix reemplaza el proceso por Bash o zsh y también puede salir silenciosamente. [plugin.json 2–11](https://github.com/obra/superpowers/blob/22f0b463e7a5e579904dd6211a520321035526f7/.claude-plugin/plugin.json#L2-L11) [hooks.json 3–12](https://github.com/obra/superpowers/blob/22f0b463e7a5e579904dd6211a520321035526f7/hooks/hooks.json#L3-L12) [run-hook.cmd 22–47](https://github.com/obra/superpowers/blob/22f0b463e7a5e579904dd6211a520321035526f7/hooks/run-hook.cmd#L22-L47) [run-hook.cmd 58–79](https://github.com/obra/superpowers/blob/22f0b463e7a5e579904dd6211a520321035526f7/hooks/run-hook.cmd#L58-L79)

**Texto exacto, por composición.** En el bloque siguiente, «ARCHIVO» representa todo el contenido de `skills/using-superpowers/SKILL.md`, desde el delimitador YAML inicial hasta su última frase, sin saltos finales. Si el archivo es ilegible se sustituye por `Error reading using-superpowers skill`. El script escapa ese texto para JSON y, en la rama Claude Code, lo entrega por stdout como `hookSpecificOutput.additionalContext` con `hookEventName=SessionStart`. Un error de escritura puede quedar silenciado. Ni el texto de brainstorming ni las referencias de herramientas se concatenan. El hook lee y emite contexto; el siguiente paso depende del agente. ### Alta · 2. La conversación es separable; el flujo original completo tiene dependencias

El diálogo se entiende como texto independiente. El frontmatter contiene nombre y descripción. El cuerpo no llama al hook ni requiere `using-superpowers` para formular preguntas. Claude puede seleccionar una skill disponible por su descripción; el wrapper incluso contempla que el plugin funcione sin inyección. Esto sustenta la viabilidad de una versión textual. Falta observar descubrimiento e invocación efectivos en la configuración concreta de Teyst. ### Alta · 3. El diseño escrito tiene consecuencias distintas según el repo

El hook no escribe diseños. **El agente** recibe la instrucción de contrastar enfoques y escribir un diseño corto o completo. En un repo el destino por defecto es `docs/superpowers/specs/YYYY-MM-DD-<topic>-design.md`, con commit; la preferencia humana prevalece. El diseño corto pasa al humano sin revisor. Para proyecto hay revisión antes de la entrega. Si todo está definido y solo hay una vía, puede aprobarse el diseño breve en el primer mensaje y luego persistirse. Hay salida directa para trabajo claro, opt-out y excepción para un spike autorizado. La fase posterior indica `docs/superpowers/plans/YYYY-MM-DD-<feature-name>.md`.
