## Cómo mantener el registro

Para cambiar un asunto, conservar su ID y registrar fecha, autoridad, fuente de la aprobación, motivo y consecuencias. Las citas anteriores son evidencia de contexto; una nueva aprobación debe quedar trazable. Ningún cambio de estado se deduce de silencio o de la mera existencia de una carpeta.

Los pendientes de esta tabla son de diseño; no reemplazan el backlog operativo del sistema existente. La migración requiere un pedido posterior explícito.

Los [antecedentes históricos](../sources.md) conservan las propuestas y decisiones de origen. El [reporte de ejecución](../superpowers/reports/2026-10-30-vcx-foundation.md) registra la instrumentación documental realizada.

La [correspondencia del primer recorrido](../architecture/current-system-mapping.md) contrasta decisiones aprobadas del kernel y estado observado en el sistema existente. Esa clasificación no cierra VCX-D011: cambiar los destinos o controles aprobados sigue requiriendo conciliación expresa.
