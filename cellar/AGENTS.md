# Contexto de trabajo de Cellar

Aplican las [instrucciones comunes](https://github.com/denispaiva/vcx/blob/main/AGENTS.md). Leer primero el [README de Cellar](README.md).

- Distinguir el producto reutilizable de los datos y decisiones de cada instancia.
- Diseñar organización, referencias y custodia preservando identidad, procedencia y una fuente editable por dato.
- Consultar [interoperabilidad](https://github.com/denispaiva/vcx/blob/main/docs/architecture/interoperability.md) para contratos y [decisiones](https://github.com/denispaiva/vcx/blob/main/docs/decisions/README.md) para propiedad, localización y múltiples instancias.
- Las plantillas son material de autoría. Sus marcadores se resuelven al instanciar; no son configuración activa ni permisos sobre el workspace.
- Evitar supuestos sobre nombres, rutas de código, proveedor de nube, equipo, repositorio o almacenamiento de una instancia.
- Una configuración de portfolio no redefine autoridad del repositorio o de otro producto. Los mecanismos ejecutables se diseñarán y verificarán en su propio alcance.
